Shortcuts

  • Raw mode - paint the selection by hand
  • Smart mode - scribble on an object; it snaps to the whole thing. Each scribble only adds to the selection near it - earlier picks stay put
  • Alt / right-drag - carve out a sub-object (Smart mode)
  • Object mode - hover to highlight a whole object, click to add it, Alt-click to remove it, or drag a box around it
  • Select people - auto-detect everyone; click a chip to keep/drop a person, then Remove
  • Fill: Auto / Pattern - Auto blends structure; Pattern rebuilds repeating texture (carpets, fabrics, bricks)
  • Remove gives you 3 fills to choose from - 1/2/3 to preview, Enter to keep, Esc to cancel
  • Edge slider - grow/shrink the selection before removing; nudge to +10 if a halo survives
  • Stamp mode - Alt-click a clean area to set the source, then paint to clone it over a flaw. Ctrl+Z undoes dabs; Apply commits
  • [ / ] - brush smaller / larger
  • E - toggle eraser (raw mode)
  • Crop mode - drag a rectangle, straighten with the slider, ⟲/⟳ for 90°, then Apply
  • Scroll - zoom (anchored at cursor) · double-click or 0 - fit · 1 - 100%
  • Space-drag or middle-drag - pan
  • Hold B - compare with the original
  • Ctrl+Z - undo the last selection scribble, then removals; Ctrl+Y - redo
